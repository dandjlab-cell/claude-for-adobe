# Organize the project

1. `project_bins` to see the tree as it is.
2. Propose the target structure in a few lines (bins and what goes where). Ask before moving anything the editor did not name.
3. `move_to_bin` with the full list of moves in one call; bins are created as needed. Each move is one Cmd+Z step.
4. Report what moved and what was skipped. Never use scripts for this.
